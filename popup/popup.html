Cấu hình Fanpage (Meta Graph API)

Chính chủ Meta

Đăng bài trực tiếp lên Fanpage của bạn thông qua Meta Graph API v19.0 mà không lo checkpoint tài khoản.

Vào Trang của bạn -> Giới thiệu -> Độ minh bạch của Trang để lấy ID.
Token có quyền pages_manage_posts và pages_read_engagement.

Soạn bài quảng bá dịch vụ

Nội dung bài viết & Đăng bài

💡 3 Bước lấy Page Access Token vĩnh viễn

1. Truy cập developers.facebook.com/tools/explorer.

2. Chọn App của bạn, tại mục User or Page chọn Trang Fanpage cần đăng.

3. Thêm quyền pages_manage_posts, pages_read_engagement rồi bấm Generate Access Token.
